Frontend Engineer (Junior)

Responsibilities

- Write component tests and fix accessibility issues flagged in audits
- Work with the backend engineer on API contracts

Requirements
- Strong JavaScript, including ES6+ and async patterns
- React, including hooks and component composition
- TypeScript in a production codebase
- CSS, including responsive layout and a utility framework
- Git and pull-request workflow
- 1+ years of experience, internships count

Nice to have
- Next.js
- Testing with Jest or Cypress
- Some design sense and comfort in Figma
